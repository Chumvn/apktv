# <img src="./icon-192.png" width="32" align="center" alt="CHUM STORE"> CHUM STORE

Kho ứng dụng Android TV & Điện thoại đồng bộ tự động từ GitHub Releases.

## Tính năng

- Giao diện đồng bộ 100% giữa App APK và Web (`Desktop`, `Mobile`, `Android TV`)
- Tự động sắp xếp ứng dụng mới tải lên sau cùng hiển thị lên trên cùng
- Hiển thị trực quan: Tên ứng dụng, Package Name, Dung lượng & Ngày cập nhật
- Chạm 1 lần để tải nhanh file `.APK` / `.XAPK`
- Tích hợp **Tải App CHUM STORE (.APK)** trực tiếp và mã QR quét tải nhanh trên Web
- Trên App Android & Android TV: hỗ trợ tự động cài đặt 1 chạm, tự động dọn rác APK sau khi cài xong hoặc khi hủy cài đặt, và **Nhận APK qua Wi-Fi (LAN Send)**
- Hỗ trợ điều hướng bàn phím / Remote TV (D-Pad), chế độ Sáng / Tối (lưu `localStorage`)

## Triển khai Web (GitHub Pages)

1. Push toàn bộ thư mục này lên nhánh `main` của repo GitHub (`Chumvn/apktv`).
2. Vào **Settings → Pages** → chọn branch `main` → Save.
3. Truy cập `https://chumvn.github.io/apktv/`.
