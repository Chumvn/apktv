# <img src="./icon-192.png" width="32" align="center" alt="CHUM STORE"> CHUM STORE

Kho ứng dụng Android TV & Điện thoại giao diện **Soft UI** đồng bộ tự động từ GitHub Releases.

## Tính năng

- Giao diện **Soft UI (Neumorphism)** Sáng / Tối đồng bộ 100% giữa App APK và Web (`Desktop`, `Mobile`, `Android TV`)
- Tự động sắp xếp ứng dụng mới tải lên sau cùng hiển thị lên trên cùng
- Hiển thị chính xác **Package Name** thực từ `AndroidManifest.xml`, **Dung lượng** và **Giờ + Ngày cập nhật**
- Khung tải Soft UI nổi hiện đại, chạm 1 lần tải & cài đặt ngay
- Trên App Android & Android TV: tự đọc package chuẩn từ APK online, tự xóa file APK sau khi cài xong hoặc khi hủy cài đặt, và **Nhận APK qua Wi-Fi (LAN Send)**
- Trên Web: hỗ trợ tải file trực tiếp hoặc quét QR tải `CHUM-STORE.apk`

## Triển khai Web (GitHub Pages)

1. Push toàn bộ thư mục này lên nhánh `main` của repo GitHub (`Chumvn/apktv`).
2. Vào **Settings → Pages** → chọn branch `main` → Save.
3. Truy cập `https://chumvn.github.io/apktv/`.
